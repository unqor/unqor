## Our mission
Deliver enterprise-quality software and open-source tooling that empowers teams to ship securely, observe effectively, and iterate quickly.

- Frontend applications and web platforms with strong UX and performance

## Contribution principles
We value clarity, predictability, and long-term maintainability:

- Small, focused changes with clear purpose are easier to review and ship.
- Tests and documentation are first-class: code without tests or docs is rarely accepted.
- Security, privacy, and backwards compatibility are considered in every release.

See CONTRIBUTING.md for step-by-step contribution guidance.

---

## Governance & releases
- We follow semantic versioning where applicable.
- Breaking changes are communicated and versioned appropriately.
- Release cadence and maintenance windows are documented per-repository.

For enterprise or partnership inquiries, contact: contact@unqor.com

---

## Security and responsible disclosure
If you discover a vulnerability, please report it privately to contact@unqor.com with a clear summary, impact, and reproduction steps. We will acknowledge receipt and coordinate a fix and disclosure timeline.

## Technology and practices
Common tools and patterns across our projects:

- Languages: TypeScript, Go, Python (choose per problem)
- Datastores: PostgreSQL, Redis
- Orchestration: Docker, Kubernetes
