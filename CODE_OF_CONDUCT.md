# Contributor Code of Conduct

As contributors and maintainers of Unqor Studio projects, we are committed to providing a welcoming, inclusive, and harassment-free experience for everyone.

This Code of Conduct is adapted from the Contributor Covenant.

## Our standards
Examples of expected behavior:
- Be welcoming and respectful in all interactions.
- Be considerate of differing viewpoints and experiences.
- Assume good faith and be open to constructive feedback.
- Use inclusive language and avoid derogatory comments.

Unacceptable behavior includes:
- Harassment, intimidation, or discriminatory language.
- Public shaming or doxxing.
- Threats, stalking, or other invasive behavior.

## Reporting
If you experience or witness unacceptable behavior, please contact the project maintainers at contact@unqor.com. Reports will be handled promptly and confidentially.

## Enforcement
Maintainers may take action to address violations, including:
- Requesting changes in behavior
- Temporarily limiting interactions (e.g., blocking)
- Removing contributors from project roles
- Closing issues or PRs that violate the Code of Conduct

## Scope
This Code of Conduct applies to all project spaces: GitHub issues and PRs, discussions, chat channels, and project meetings.
